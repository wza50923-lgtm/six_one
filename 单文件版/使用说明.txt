六个一 · 语文素材本 —— 单文件离线版 使用说明

1. 本文件夹里只有一个 HTML 文件，双击即可在电脑浏览器（推荐 Chrome / Edge）打开；
2. 需要 AI 功能（一键生成 / AI 补充 / 联网素材）时，请每个使用者在右上角「⚙ 设置」里填写【自己的】DeepSeek API Key（在 platform.deepseek.com 申请，Key 只保存在自己浏览器里）；
3. 不填 Key 也能用：内置格言/好诗/美文/素材 + 手动编辑 + 勾选 + 导出 TXT/Word；
4. 说明：
   - 打开方式是"离线文件"，浏览器可能限制联网接口（CORS）——AI/热榜失败时请改用手动粘贴素材；
   - 「保存到项目文件夹」在离线打开时可能不可用，请用「导出素材包(.js)」或 TXT/Word 导出；
   - 每个用户的勾选和编辑保存在各自的浏览器里，互不相通；
5. 想用联网完整版（PWA、自动更新、手机可用），请使用项目中的 sixone/ 完整版并部署到 GitHub Pages。
